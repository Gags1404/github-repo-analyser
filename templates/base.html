What is GitHub Repository Analyzer?

GitHub Repository Analyzer is a powerful tool that provides detailed insights into public GitHub repositories. It analyzes code, contributors, commit patterns, and more to give you a comprehensive understanding of any repository.

Key Features

  • Detailed commit activity analysis
  • Language breakdown and statistics
  • Contributor insights and contributions
  • Repository timeline visualization
  • Repository health score
  • Branch and fork analysis
Technologies Used
Python Flask SQLAlchemy Bootstrap 5 Chart.js GitHub API Docker
Privacy & Data

We only analyze public repositories and do not store any sensitive information. All analyses are cached for performance but can be cleared at any time.
